# Amazon Homepage Clone

A responsive front-end clone of the Amazon homepage built to practice modern UI layout, CSS styling, and navigation components.

---

## 🚀 Features

* **Header & Navigation:** Includes Amazon branding logo, location selector, search bar, language switcher, account menus, and cart icon.
* **Hero Banner:** Full-width background banner showcasing featured deals and promotional sections.
* **Product Card Grid:** Multi-column box layout displaying product categories, deals, and recommendations.
* **Footer Navigation:** Multi-level footer featuring "Back to top", informative link columns, language/currency selectors, and copyright details.
* **Responsive Design:** Adapted to fit various screen sizes using flexible CSS layouts.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structure and page layout.
* **CSS3:** Custom styles, Flexbox, CSS Grid, and responsive media queries.
